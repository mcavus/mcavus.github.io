# mcavus.com

My personal site. Live at **[mcavus.com](https://mcavus.com)**.

Plain HTML, CSS and a little vanilla JavaScript, hosted on GitHub Pages.

My blog lives at **[mcavus.com/blog](https://mcavus.com/blog)**
([source](https://github.com/mcavus/blog)), built with
[Overprint](https://overprint.mcavus.com/).

## Structure

```
├── index.html          home
├── site.html           colophon
├── 404.html            not-found page
├── assets/
│   ├── css/style.css   all styles + theme tokens
│   ├── js/theme.js     light/dark toggle, footer year
│   ├── js/analytics.js Cloudflare Web Analytics (cookieless)
│   └── img/            portrait, share card, 404 artwork
├── favicon.*           icons
├── CNAME               custom domain
├── robots.txt          crawl rules
└── sitemap.xml
```
